# 教师端领域

使用 `domains --query <教师原话>` 找到准确领域，再把宿主生成的结构化意图交给 `intent` 获取该领域内的 typed action 候选。不要仅凭本表、目录排序或英文标识猜动作。

- 账号与个人空间：登录状态、空间入口、笔记、收件箱、通讯录、群组、个人直播。
- 课程与班级：我教的课、班级、学生、教师团队、班级设置与权限。
- 教学内容：章节、课程资料、云盘、课程资源、课件、教案和附件。
- 作业与评价：作业发布、提交情况、批阅、评分、评语、退回与统计。
- 考试与题库：考试管理、试卷、题库、题目、阅卷、成绩提交和导出。
- 通知与讨论：课程通知、个人通知、讨论主题、回复、置顶和删除。
- 学情与活动：成绩统计、学习监控、课堂活动、任务引擎和完成状态。
- 智能教学：课程图谱、知识图谱、AI 工作台、AI 知识库和检测服务。
- 其他教师相关空间能力：学科资源、岗位能力、直播和当前账号实际开放的教师工作入口。

教师端明确排除：我学的课、学生课程活动、学生作答或答题入口、学生考试、自测、学生错题、学生学习记录和学生端课程图谱。课程名或功能名看似相同也不能跨到学生端入口。

能力状态含义：

- `observed`：当前界面或响应中观察到入口，不代表已有可执行动作。
- `implemented`：已有 HTTP 实现和本地测试，不自动代表当前账号实测成功。
- `live_verified`：已有真实账号验证记录；仍需以本次账号返回的可观察后置条件判断结果。
