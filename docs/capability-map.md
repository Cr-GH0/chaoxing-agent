# 能力地图

本页记录 2026-09-01 代码目录与当前教师账号页面的核对结果。它描述已经建模的动作和当前平台状态，不代表其他学校、角色或未来版本一定暴露相同功能。

## 状态总览

| 状态 | 数量 | 含义 |
| --- | ---: | --- |
| `implemented` | 530 | 存在可调用的动作、统一运行时分发和测试 |
| `live_verified` | 369 | 该动作已在真实平台上执行并检查后置条件 |
| `implemented` 但未标记实测 | 161 | 已实现并有自动测试，但当前账号未安全执行该精确动作 |
| `observed` surface marker | 31 | 17 个课程入口和 14 个个人空间入口的导航事实 |

`observed` 是入口标记，不等于 31 个未实现功能。例如“课程图谱”既有一个入口标记，也有 42 个具体语义动作。

能力响应中的 `surface_coverage` 会把每个入口映射到对应语义领域和已实现动作数量；平台当前只提供通用入口读取、没有独立对象操作的页面标记为 `generic_entry_only`。

运行以下命令取得机器可读的完整动作列表：

```powershell
uv run chaoxing-agent capabilities
```

## 当前个人空间入口

当前个人空间观察到 14 个入口：课程教学、达成度、岗位能力、课程大纲管理、笔记、收件箱、消息、小组、云盘、通讯录、大雅AIGC检测、个人直播间、大雅相似度检测、专题创作。

当前账号实测边界：

- “达成度”入口可通过 HTTP 打开，但当前返回“暂无数据”，因此没有可继续建模的对象操作；
- “消息”入口当前返回“系统维护中，功能暂时无法使用”；
- “课程大纲管理”入口当前没有 `data_url`，运行时把它报告为不可用；
- “岗位能力”的公开招聘、职业百科和行业岗位库可用；学校专属岗位库当前未开放，`job_ability.status.read` 会返回该权限事实；
- 其余有独立对象模型的入口已经进入对应语义领域。

上述状态可能随学校配置和平台维护变化，应以重新执行 `space.modules.discover`、`space.module.open` 和领域状态动作的结果为准。

## 实测标记原则

只有满足以下条件才设置 `live_verified=True`：

1. 使用真实认证会话调用正式 HTTP 实现；
2. 没有依赖打开的浏览器或客户端；
3. 读取动作取得预期结构，或写动作完成回读/消失/状态比对；
4. 临时测试对象被恢复或残留被明确记录。

对删除、成绩、成员、权限、付费等会影响真实人员或数据的动作，如果当前账号没有安全代表性对象，就保留“已实现但未实测”状态，不用破坏性操作换取标记。
