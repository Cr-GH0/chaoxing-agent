# 能力地图

本页记录 2026-09-01 代码目录与当前账号教师、学生及个人空间页面的核对结果。它描述已经建模的动作和当前平台状态，不代表其他学校、角色或未来版本一定暴露相同功能。

## 状态总览

| 状态 | 数量 | 含义 |
| --- | ---: | --- |
| `implemented` | 549 | 存在可调用的动作、统一运行时分发和测试 |
| `live_verified` | 391 | 该动作已在真实平台上执行并检查后置条件 |
| `implemented` 但未标记实测 | 158 | 已实现并有自动测试，但当前账号未安全执行该精确动作 |
| `observed` surface marker | 43 | 17 个教师课程入口、14 个个人空间入口和 12 个学生课程入口的导航事实 |

`observed` 是入口标记，不等于 43 个未实现功能。例如教师侧“课程图谱”既有一个入口标记，也有 42 个具体语义动作；学生侧 12 个入口中已有 11 个对应独立只读语义领域，只有直播课/见面课仍只有通用入口读取。

能力响应中的 `surface_coverage` 会把每个入口映射到对应语义领域和已实现动作数量；平台当前只提供通用入口读取、没有独立对象操作的页面标记为 `generic_entry_only`。

运行以下命令取得机器可读的完整动作列表：

```powershell
uv run chaoxing-agent capabilities
```

## 当前学生课程入口

“课程教学”中的“我学的课”通过独立学生课程列表接口读取。当前账号实测返回 9 门学生身份课程；课程名、班级 ID、个人课程标识和入口地址均从当前会话响应解析，不写死在代码中。

在当前账号的一门完整学生课程页中观察到 12 个入口：AI助教、任务、章节、讨论、作业、考试、资料、错题集、学习记录、课程图谱、自测、直播课/见面课。不同课程实际开放的入口不同，`learning.course.modules.discover` 每次从所选课程当前页面动态解析，`learning.course.module.open` 按学生页面使用的参数规则构造 HTTP 请求。

其中 11 类内容已有 14 个独立语义动作：

- `learning.course.activities.list` 聚合课堂活动、学习计划任务和 AI 练习活动，但不打开任务；
- `learning.course.chapters.list` 读取单元、章节编号、标题和待完成任务点；
- `learning.course.discussions.list` 读取课程讨论，并在班级范围内安全进行本地关键词筛选；
- `learning.course.homeworks.list`、`learning.course.exams.list` 和 `learning.course.self_tests.list` 只解析列表页，不进入项目、启动作答、改变计时或提交状态；
- `learning.course.materials.list` 读取资料根目录或指定的一级文件夹，不预览、下载或增加浏览次数；
- `learning.course.ai_tools.list`、`learning.course.wrong_questions.summary` 和 `learning.course.records.read` 分别读取可用 AI 工具、错题概况和十二类学习指标，并剔除身份与页面启动令牌。
- `learning.course.knowledge_graph.list`、`learning.course.knowledge_graph.node.read`、`learning.course.knowledge_graph.models.list` 和 `learning.course.knowledge_graph.model.read` 读取学生可见图谱、单个节点、图谱模型目录与指定模型层级，不返回 `enc`、`stuenc` 或导出令牌。

上述 14 个动作均已通过保存的登录会话直接执行。当前账号实测发现真实课堂活动、66 个章节、讨论话题、作业和资料；课程图谱包含 276 个节点、431 条关系和 7 个图谱模型。考试与自测当前为空，因此空列表行为已经实测，真实考试/自测条目的解析仍缺少当前账号样本。

“直播课/见面课”跳转到 `xueyinonline.chaoxing.com` 后要求额外的 Passport SSO，当前保存会话会被送回登录页。运行时会明确报告该认证边界，不把登录页当作模块内容。

在线学习诚信承诺状态由页面的账号级与课程级标志共同判断。页面含有承诺书 HTML 不代表当前必须签署；`learning.course.integrity.read` 返回实际判断。`learning.course.integrity.accept` 会代表当前账号改变平台承诺状态，因此必须经过一次性确认门，当前未执行实测。

## 当前个人空间入口

当前个人空间观察到 14 个入口：课程教学、达成度、岗位能力、课程大纲管理、笔记、收件箱、消息、小组、云盘、通讯录、大雅AIGC检测、个人直播间、大雅相似度检测、专题创作。

当前账号实测边界：

- “达成度”入口可通过 HTTP 打开，但当前返回“暂无数据”，因此没有可继续建模的对象操作；
- “消息”入口当前返回“系统维护中，功能暂时无法使用”；
- “课程大纲管理”入口当前没有 `data_url`，运行时把它报告为不可用；
- “岗位能力”的公开招聘、职业百科和行业岗位库可用；学校专属岗位库当前未开放，`job_ability.status.read` 会返回该权限事实；
- 大雅相似度、AIGC 和两两比对当前均没有检测记录，因此记录状态、支付状态和报告下载动作没有可安全复用的真实对象；
- 通讯录当前没有自建团队；个人小组中没有当前账号可管理的小组，因此没有为团队成员和小组管理员权限读取动作伪造测试对象；
- 六门当前课程的题库下载中心均已通过 HTTP 读取，共发现 45 条记录；`question_bank.downloads.get` 已对一条就绪记录取得下载信息且未落盘；
- 作业草稿标题修改已完成“改名—恢复原名”验证；题目新增与修改已在一个未发布测试草稿中逐字段回读，草稿保持未发布，整体删除仍受一次性确认门保护；
- 其余有独立对象模型的入口已经进入对应语义领域。

上述状态可能随学校配置和平台维护变化，应以重新执行 `space.modules.discover`、`space.module.open` 和领域状态动作的结果为准。

## 实测标记原则

只有满足以下条件才设置 `live_verified=True`：

1. 使用真实认证会话调用正式 HTTP 实现；
2. 没有依赖打开的浏览器或客户端；
3. 读取动作取得预期结构，或写动作完成回读/消失/状态比对；
4. 临时测试对象被恢复或残留被明确记录。

对删除、成绩、成员、权限、付费等会影响真实人员或数据的动作，如果当前账号没有安全代表性对象，就保留“已实现但未实测”状态，不用破坏性操作换取标记。
